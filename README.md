One haiku about debugging, in the 5-7-5 syllable shape: a breakpoint holds its breath, log lines scroll past with no clues, and dawn finds the typo — the bug was mine all along. The program writes the haiku to `/output/entry.txt` and asserts the form (three lines, 5-7-5 syllables, at most 200 characters) before writing, so what lands in the file is always a valid entry.

## Run it

```sh
python3 main.py
```
